Version Control with Git

Quản lý thay đổi như các snapshot có thể review, truy vết và phục hồi.

commitbranchPRrebase
Mental model

Working tree → staging → local commit → remote. Branch là con trỏ, HEAD là vị trí hiện tại.

Phải làm được

Tạo branch, chia commit nhỏ, resolve conflict, mở PR có test và impact.

Bẫy thường gặp

Commit secret/data lớn; force push branch chung; add tất cả mà không xem diff.

Quick comparison

Những cặp dễ nhầm

Khái niệmKhác biệt cần nhớ
OLTP vs OLAPGiao dịch nhỏ/latency thấp vs scan và aggregate dữ liệu lớn.
Batch vs StreamingTập dữ liệu hữu hạn theo interval vs event liên tục; chọn theo SLA thực tế.
Retry vs ReplayThử lại thao tác transient vs xử lý lại dữ liệu lịch sử từ nguồn/raw.
Backup vs RedundancyKhôi phục phiên bản/trạng thái vs duy trì khả dụng khi hạ tầng lỗi.
Monitoring vs ObservabilityBiết có vấn đề vs đủ tín hiệu để giải thích nguyên nhân.
Rollback code vs dataĐổi artifact về bản cũ không tự đảo các record đã ghi.
Không tìm thấy nội dung phù hợp. Thử một từ khóa khác.
